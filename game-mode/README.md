# Portfolio Game Mode

A gamified version of the portfolio where users can explore a pixelated room to discover different portfolio elements.

## Current Features

### Step 1: Basic Game Setup ✅
- Pixelated 2D canvas-based game
- Character movement with arrow keys (WASD also works)
- Basic mobile touch controls
- Simple room with checkered floor and walls
- Exit button to return to main portfolio

### Step 2: Interactive Objects ✅
- Certificate Frame (purple) - represents certificates
- Computer Desk (green) - represents projects
- Bookshelf (yellow) - represents skills/education
- Click on objects to see placeholder information
- Objects highlight when character is near them

## Controls
- **Desktop**: Arrow keys or WASD to move
- **Mobile**: Touch and drag in direction you want to move
